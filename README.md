# Calculator

This mod adds a /math command that can solve simple math equations in-game!

---

### Supported Versions

- 1.20.4

**This mod will be updated to 1.21 soon!**

---

### Features

/math [num1] [operation] [num2]

Operations:

"+", "plus", "add"

"-", "minus", "subtract"

"*", "times", "multiply"

"/", "dividedby", "divide"

**"*" and "/" may not work because of Minecraft!**
