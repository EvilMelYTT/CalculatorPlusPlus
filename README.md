This mod adds a /math command that can solve simple math equations in-game!

---

- 1.21.11

- 1.21.1

- 1.20.4

**Support for this project will be reinstated for as long as I remember this exists**

---

### Features

/math [num1] [operation] [num2]

Operations:

"+", "plus", "add"

"-", "minus", "subtract"

"times", "multiply"

"dividedby", "divide"
